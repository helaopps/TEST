# TravelMate Platform

A multi-role travel platform connecting travelers with locals, service providers, event organizers, and merchants.

## 🎯 Core Features
- Role-based dashboards (Traveler, Local, Admin, etc.)
- Interactive trip planning with Google Maps API
- Social feeds and booking systems
- Admin moderation panel
- Payment integration
- Mobile-first responsive design

## 🚀 Getting Started
1. Clone the repository
2. Install dependencies (`npm install`)
3. Set up environment variables
4. Run the application (`npm run dev`)

## 🛠️ Tech Stack
- Backend: Node.js, Express, MongoDB/PostgreSQL
- Frontend: React, React Native (for mobile)
- Authentication: JWT
- Payment: Stripe/PayPal
- Maps: Google Maps API
